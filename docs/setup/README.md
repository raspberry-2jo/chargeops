# 설치 기록 (docs/setup)

각자 맡은 설치를 하면서 **친 명령어와 메모를 여기에 남김.**
VM을 다시 만들거나 다른 사람이 같은 환경을 만들 때 이 문서만 보고 따라 할 수 있게 쓰는 게 목표.

## 파일 규칙
- 주제 하나에 파일 하나: `rocky.md`, `postgres.md`, `pgbouncer.md`, `k8s.md` 처럼 소문자 영어
- 새 파일은 `_template.md`를 복사해서 시작
- 버전은 각 파일에 따로 적지 말고 `versions.md`에만 적음

## 절대 적지 않는 것
- 비밀번호, 토큰, 키, 실제 접속 IP
- 필요하면 `<각자 설정>`, `<VM IP>` 처럼 비워서 적음

## 올리는 방법
설치 하나 끝날 때마다 내 브랜치에 커밋 → push → dev로 PR (작업 하나 = PR 하나)
